# Privacy policy

_Last updated: 8 October 2026_

OCVYN is a VS Code extension that shows CSV, TSV and spreadsheet files as a read-only grid.

**OCVYN does not collect, store, send or share any data.**

- **No telemetry, no analytics, no tracking.** OCVYN contains no code that reports usage.
- **No network access.** OCVYN makes no network requests. Your files never leave your machine.
- **Files are only read, never written.** OCVYN opens the file you choose, in memory, inside VS Code. It does not change, copy or upload it.
- **Clipboard:** OCVYN writes to your clipboard only when you copy (⌘C / Ctrl+C or "Copy column values"). It never reads your clipboard.
- **No accounts, no cookies, no personal data.**

VS Code itself, and the Visual Studio Marketplace or Open VSX that you install OCVYN from, have their own privacy policies; they are not covered here.

Questions: open an issue at https://github.com/jha-adrs/ocvyn/issues.
